# PDFutl

PDF-просмотрщик на Code-OSS, EmbedPDF 3.3.0 и локальном PDFium WebAssembly. Исполняемая среда — Electron 45.4.1. [Code-OSS](https://github.com/microsoft/vscode) · [EmbedPDF](https://github.com/embedpdf/embed-pdf-viewer) · [Electron 45.4.1](https://github.com/electron/electron/releases/tag/v45.4.1)

## Portable-версия

Релиз содержит архивы для Windows x64 и Linux x64. Для запуска распакуйте архив своей платформы в разрешённую пользовательскую папку. [Скачать релиз](https://github.com/leonmaks/PDFutl/releases/latest) · [Инструкция для Windows и SberOS](INSTALL.md)

## Запуск из исходников

Запустите из корня проекта в PowerShell.

```powershell
.\pdfutl.cmd 'C:\Documents\Review A.pdf' 'C:\Documents\Review B.pdf'
```

Профиль и история файлов находятся в `.upstream/profile`. Указанные в команде PDF открываются в отдельном окне документов. При запуске `.\pdfutl.cmd` без аргументов приложение восстанавливает окно, группы вкладок, страницу, масштаб и прокрутку каждого PDF. Два вида одного файла сохраняют положение независимо. В открытом окне добавляйте файлы через **File → Open File…**.

Окно документов работает без доверенной рабочей папки. Ограничения Code-OSS для недоверенного окна действуют в фоне. PDF обрабатывает локальный PDFium в веб-представлении. Новые комментарии и выделения сохраняются в профиле PDFutl для этого файла и восстанавливаются при открытии.

Верхнее меню использует нативные меню Code-OSS и показывает команды для работы с PDF. **Edit → Find** и `Ctrl+F` открывают и закрепляют одну панель поиска. **Go → Go to Page…** и `Ctrl+G` активируют поле номера страницы. **View** управляет навигатором, раскладкой и масштабом активного PDF, а масштаб интерфейса находится в **View → Appearance**. **Annotations** содержит выделение последним использованным цветом, добавление комментария к выбранному тексту и список комментариев текущей страницы.

- По умолчанию меню, навигатор, вкладки, строка состояния и панели PDF используют тему **Darcula**. Палитра включена в приложение и доступна в меню выбора цветовой темы.
- `Ctrl+B` показывает и скрывает навигатор Explorer. На Windows используется физическая клавиша `B` независимо от раскладки. **Open Editors** показывает вкладки по группам, как в VS Code.
- Новый PDF открывается крайней левой вкладкой своей группы и появляется первым в списке **Open Editors** этой группы. Вкладку можно переместить вручную.
- В **Pinned Folders** кнопка `+` закрепляет папки в профиле. При наведении на заголовок или папку появляются кнопки сортировки по имени и времени изменения. Повторное нажатие меняет направление. Заголовок управляет списком закреплённых папок, у каждой папки есть собственный порядок для её содержимого.
- Справа от папок и PDF показано время изменения. Кнопка с часами в заголовке скрывает или возвращает даты во всём разделе. Кнопка на папке управляет датами в её содержимом и вложенных папках. `Ctrl+Alt+F` ищет по именам в дереве, а **Refresh Pinned Folders** перечитывает содержимое и даты.
- **Outline** в навигаторе показывает встроенные закладки активного PDF и их вложенность. Щелчок по закладке с внутренней ссылкой переносит к указанному месту документа.
- **Timeline** показывает открытия PDF, сохранённые копии, выделения, добавление и редактирование комментариев. Запись об открытии появляется после успешной загрузки PDF в редактор, в том числе при повторном открытии после закрытия. Восстановление вкладок, просмотр страниц и поиск не добавляют событий. Новые события подписываются именем текущей учётной записи. Щелчок по записи сохранённой версии открывает PDF с аннотациями на момент сохранения.
- Щелчок по событию аннотации в **Timeline** переносит к соответствующему фрагменту PDF и обводит его. Снимки и история хранятся в профиле PDFutl.
- В контекстном меню вкладки доступны **Split Right** и **Split Down**. Двойной щелчок разворачивает группу. Повторный возвращает раскладку.
- `Ctrl+F` открывает и закрепляет верхнюю панель поиска и масштаба. Откреплённая панель появляется через 200 мс после движения или нажатия мыши в любой части превью PDF. Вне панели она скрывается после 350 мс без движения. Шеврон в поле поиска открывает список совпадений, а кнопка с ползунками показывает параметры поиска. Стрелки и `Enter` / `Shift+Enter` переходят между совпадениями. Для текущего и остальных совпадений используются разные цвета активной темы.
- Выделите текст, чтобы открыть палитру из четырёх цветов и кнопку комментария. Значок над отмеченной строкой открывает существующий комментарий. Щелчок по выделению открывает карточку, где можно добавить или отредактировать комментарий. **File → Save As…** или `Ctrl+Shift+S` экспортирует отдельный PDF с аннотациями из открытого вида.
- `Ctrl+Z` и **Edit → Undo** отменяют последние выделения, добавления и правки комментариев в открытой вкладке PDF. Сочетание работает по физической клавише `Z` в любой раскладке. В поле комментария `Ctrl+Z` отменяет ввод текста. Timeline хранит исходные действия и записи об их отмене.
- `Ctrl+Shift+M` и кнопка комментариев на плавающей панели показывают авторов и тексты комментариев текущей страницы. Сочетание работает на физической клавише `M` в любой раскладке Windows.
- `Ctrl` + колесо мыши над превью меняет масштаб PDF, а над навигатором, вкладками и другими элементами рабочего окна — масштаб интерфейса. Масштабы независимы. Для PDF также доступны **Fit page** и поле масштаба от `25` до `4000` процентов.
- `F11` разворачивает активный PDF на весь экран. Для выхода нажмите `F11` или `Esc`. Панель появляется через 200 мс после движения или нажатия мыши. Её можно закрепить или перетащить за значок слева.
- В многостраничном PDF нажмите на текущий номер в правом нижнем углу превью, введите номер нужной страницы и нажмите `Enter`.

Подсветка рисуется отдельным слоем под растром PDF. Растр смешивается с фоном в режиме `multiply`, чтобы белая бумага пропускала цвет, а чёрный текст сохранял цвет. На цветном тексте и сплошных заливках итог зависит от цветов PDF. Сканам нужен текстовый слой для поиска.

## Сборка и проверка

```powershell
npm ci
npm run build
npm run typecheck
npm run build:code-oss
npm run smoke
```

`build:code-oss` загружает исходники Code-OSS `1.147.0`, переключает его нативную сборку на Electron `45.4.1` и собирает рабочую область. Для сборки нужны Node.js 24.22.1 или новее из ветки 24, pnpm, Python и MSVC v143 с библиотеками Spectre. Распакуйте официальный архив Windows x64 Electron 45.4.1 в `.upstream/electron-45.4.1` после проверки SHA-256. [Релиз Electron и контрольные суммы](https://github.com/electron/electron/releases/tag/v45.4.1) · [Требования Code-OSS](https://github.com/microsoft/vscode/wiki/How-to-Contribute)

`npm run smoke` создаёт два тестовых PDF и запускает интеграционный тест в отдельном профиле. `npm run smoke -- --viewer` проверяет PDF-редактор в изолированном окне того же Electron. `npm run smoke -- --menus` проверяет верхнее меню приложения с тестовым PDF. Скриншоты и сохранённый тестовый PDF появляются в `.smoke`.

### Portable-архив из собранного Code-OSS

На целевой системе соберите нативные зависимости Code-OSS для Electron 45.4.1. В корне подготовленного Code-OSS создайте сборку рабочей области.

```sh
node build/next/index.ts bundle --out out-pdfutl --target desktop --minify --mangle-privates --nls
```

В корне PDFutl выполните `npm ci` и `npm run build`, затем укажите скрипту упаковки подготовленный Code-OSS, его сборку, проверенный официальный ZIP Electron для текущей платформы и папку результата. Для Windows скрипт использует системный `tar`, для Linux нужны `unzip` и `tar`.

```sh
node scripts/portable.mjs .upstream/code-oss .upstream/code-oss/out-pdfutl /path/to/electron.zip .upstream/portable
```

Чтобы проверить архив на целевой платформе, распакуйте его в отдельную тестовую папку и передайте путь к её исполняемому файлу команде `npm run smoke -- --portable=/path/to/pdfutl`.
